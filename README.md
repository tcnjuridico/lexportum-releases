# LEXPORTUM — downloads

Aqui ficam só os **instaladores** dos jogos da [LEXPORTUM](https://www.lexportum.com). O código dos jogos não fica aqui.

## THE FINAL CROWN

RPG de ação em mundo aberto. **Beta para Windows.**

- Página oficial e download: https://www.lexportum.com/the-final-crown/
- Cada versão é uma *Release*, com:
  - o instalador para Windows (`TheFinalCrown-Setup-X.Y.Z.exe`), que não pede administrador;
  - a versão portátil (`.zip`), para extrair e jogar;
  - o SHA-256 de cada arquivo, para conferir o download.
- Requisitos: Windows 10 ou 11 (64 bits), 4 GB de memória, placa de vídeo com Vulkan ou DirectX 12, 1 GB livre.
- O Windows pode mostrar "O Windows protegeu o computador": o instalador ainda não tem assinatura digital. Clique em
  "Mais informações" e "Executar assim mesmo".
